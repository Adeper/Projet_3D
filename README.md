# PROJET 3D : GÉNÉRATION PROCÉDURALE DE TERRAINS ET DE ROUTES

*Auteurs: BES Jean-Baptiste - BONBON-PERIAC Adam*

Étape 0 :
Se placer dans le dossier ```code``` :
```console
cd code
```

Étape 1 :
Pour compiler :

Sur Linux
```console
sh compile_linux.sh
```
Sur Windows
```console
sh compile_windows.sh
```

Étape 2 :
Pour exécuter :

Sur Linux
```console
sh launch_linux.sh
```

Sur Windows
```console
sh launch_windows.sh
```
